# Clean-room specs: pixel-vfx

These specs are the only thing that crossed from the reference project to the
writers of `skills/pixel-vfx` and `skills/pixel-vfx-library`.

- **Reference:** [patch-gg/pixelfx](https://github.com/patch-gg/pixelfx), MIT,
  commit `a841596`.
- **Spec side:** one person read the reference and wrote these files in their
  own words. They describe behaviour and ideas, and name effects only by short
  briefs. They hold no text or code from the reference.
- **Writer side:** separate writers who never opened the reference built the
  skills, the tool and every example effect from these files alone.

| Spec | What it covers |
| --- | --- |
| [1-skill-and-tool.md](1-skill-and-tool.md) | The method, effect model, quality bar, engines, and the render, sheet and check tool |
| [2-acts-moves-previews.md](2-acts-moves-previews.md) | Stand-in character and acts, on-body effects, moves, GIF and compare previews, toolkit breadth, library commands |
| [3-library.md](3-library.md) | The example effect library: page format and one brief per effect |
