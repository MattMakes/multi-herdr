# Video pipeline

The orchestrator's video recipe ships inside the `orchestrate` skill, so an
orchestrator in any project can read it:
[skills/orchestrate/references/video-pipeline.md](../../skills/orchestrate/references/video-pipeline.md).

It gives the 6 waves, the project layout, the files each `video-*` teammate
owns, and the gate command and pass rule of each wave. The teammates are in
[teammates/README.md](../../teammates/README.md), and the skills are in
[skills/README.md](../../skills/README.md).
