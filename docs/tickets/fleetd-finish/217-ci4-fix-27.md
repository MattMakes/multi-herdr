## Faults

10 Linux tests of `p4_no_loss.rs` and `p6_features.rs` fail: the pass helper of the test gives fleetd a PATH with only an empty `no-clis` folder, so on Linux the host tools (git, bwrap, socat, setsid) are not found. The report proposes: keep the empty `no-clis` folder first and append the host tool folder of the harness (`harness.rs` `host_bin`), Linux only. Verify the cause first in the Linux container.
