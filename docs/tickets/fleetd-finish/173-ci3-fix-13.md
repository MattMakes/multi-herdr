## Fault and goal

About 107 e2e tests fail on Linux: `sandbox is not supported on linux: bwrap is not on PATH`. Cause: `seal` in `crates/horch-e2e/src/harness.rs` (near line 375) sets `PATH` to the folder of the fakes only, so fleetd cannot find `/usr/bin/bwrap` and `/usr/bin/socat`. Fix: on Linux only, add the folders of the real `bwrap` and `socat` after the folder of the fakes (find them from the `PATH` of the test process; do not hard-code 1 folder). No other tool of the host may become visible: add only a folder made for the test that holds links to these 2 tools. macOS must not change: the Check proves that.

## Linux proof
