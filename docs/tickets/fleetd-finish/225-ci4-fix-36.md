## Faults

163 Windows tests fail because a path from `canonicalize()` (with the `\\?\` prefix on Windows) goes to `git worktree add` and other git calls, which refuse it. Places: `crates/horch-core/tests/bisect.rs:96`, `crates/horch-core/src/fleetd/task_execution/application/launch.rs:485` and each other `canonicalize()` whose result reaches git or a child process. Fix it in 1 place of the product: a function of `horch-platform` that gives a path for a child process with no verbatim prefix on Windows (a no-op on Unix; PL-2: the OS `cfg` lives in `horch-platform`), and use it at each call. List each `canonicalize()` of `crates/*/src` in the commit message with: reaches a child or not. `launch.rs` is a shared file (not in Own): change only the path line. The Check compiles the Windows target; the proof on Windows is the next CI run.
