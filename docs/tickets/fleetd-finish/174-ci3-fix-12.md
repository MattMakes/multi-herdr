## Fault and goal

27 tests fail on Linux: `refusing to launch without a sandbox: bwrap and socat not on PATH`. Cause: `LaunchEnv::for_test()` (`crates/horch-core/src/harness/launch.rs`, near line 153) has `path: None`. Fix: give the test env a folder with a fake `bwrap` and a fake `socat`, as `crates/horch-core/src/harness/claude.rs` near line 1665 and task T-193 do. Change test code and `for_test` only: the product rule (refuse a launch with no sandbox) must stay, and a test of that refusal must stay green.
