  `horch ledger add-map --dry-run`, then queue with `add-map`.

  safety: temporary HORCH_* folders, never install, never start a dev daemon on the live ledger).

  handed to the operator. Windows results come only from CI (CI runs on a PR to main or
  workflow_dispatch), so the operator must open a draft PR for the Windows proof.

  then), fast gate = workspace tests without horch-e2e, requeue restores the single replan = yes?,
  no sandbox = no worker.

  merges the design tip into `fleet/fleetd-build`.
