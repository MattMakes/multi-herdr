Extra finding for your ticket, from the review of T-287 (F4): CliWorktreeGit loads the global git config of the user. A .gitattributes of the project can then select a global filter program (for example git-lfs) during the git add -A of a rescue or remove snapshot. Fix it in the 1 runner of adapters/git.rs (GIT_CONFIG_GLOBAL=/dev/null, GIT_CONFIG_NOSYSTEM=1, or the sandbox), and change the rescue snapshot and the remove snapshot together, so that both compare the same bytes. Test a repository with an lfs-style filter in the global config. Task T-288 also edited adapters/git.rs (reattach of an existing branch): bring the run branch in first.
